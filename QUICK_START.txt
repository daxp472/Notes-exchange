✅ STEP 5: DEPLOY TO RENDER

1. Push code to GitHub
2. Go to render.com → Create Web Service
3. Connect your GitHub repository
4. Settings:
   - Environment: Node
   - Build Command: npm install
   - Start Command: npm start
   - PORT: 5001

5. Environment Variables section - Add these from backend/.env:
   - SUPABASE_URL
   - SUPABASE_ANON_KEY
   - SUPABASE_SERVICE_ROLE_KEY
   - JWT_SECRET
   - JWT_EXPIRE=7d
   - CLOUDINARY_NAME
   - CLOUDINARY_KEY
   - CLOUDINARY_SECRET
   - NODE_ENV=production
   - PORT=5001
   - FRONTEND_URL (update later)

6. Click Deploy

7. Wait 5-10 minutes
8. Copy your Live URL (e.g., https://studyhub-xyz.onrender.com)

═══════════════════════════════════════════════════════════════

✅ STEP 6: DEPLOY FRONTEND TO NETLIFY

1. Update frontend/.env.local:

VITE_API_URL=https://studyhub-xyz.onrender.com/api
(Replace with your actual Render URL)

2. Push to GitHub
3. Go to netlify.com → Add new site → Import from Git
4. Select your repository
5. Build settings:
   - Build command: npm run build
   - Publish directory: dist
6. Add Environment Variables (from frontend/.env.local)
7. Deploy
8. Copy your Netlify domain

═══════════════════════════════════════════════════════════════

✅ STEP 7: UPDATE BACKEND FRONTEND_URL

❌ TROUBLESHOOTING:

"Cannot connect to backend"
→ Check Render URL in frontend/.env.local is correct
→ Check Render deployment is active

"Unauthorized errors"
→ Check JWT_SECRET is filled in backend/.env
→ Try logging out and logging back in

"Database connection error"
→ Check Supabase keys are correct
→ Run DATABASE_SETUP.sql again

"NotesPage doesn't load"
→ Check notes table exists in Supabase
→ Check user has uploaded at least 1 note
