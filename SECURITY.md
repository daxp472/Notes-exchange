## 🚨 Reporting a Vulnerability

Security of student data, authentications, and uploaded academic documents is of paramount importance.

If you find a security vulnerability, **please DO NOT create a public GitHub issue**. Instead, please report it privately:

1. **Email**: [daxpatel.cg@gmail.com](mailto:daxpatel.cg@gmail.com)
2. **Subject Line**: `[SECURITY VULNERABILITY] - College Notes Exchange`
3. Include:
   - Detailed description of the issue
   - Step-by-step reproduction instructions or proof-of-concept
   - Impact assessment

We will acknowledge your report within 48 hours and work with you on a swift resolution.
